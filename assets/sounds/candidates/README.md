# Disco Type sound candidates

These are short, local WAV one-shots sourced from Mixkit for auditioning.
The current prototype does not play them yet.

## Candidate palette

1. `soft-typewriter-click.wav` — 219 ms
   - Source: Mixkit sound effect 1125, “Typewriter soft click”
   - Character: soft, papery, slightly vintage
   - Best use: quiet per-character feedback

2. `laptop-key-press.wav` — 264 ms
   - Source: Mixkit sound effect 2541, “Single key press in a laptop”
   - Character: balanced, tactile, unobtrusive
   - Best use: recommended per-character sound

3. `hard-laptop-key-press.wav` — 306 ms
   - Source: Mixkit sound effect 2542, “Hard single key press in a laptop”
   - Character: firmer attack, more mechanical presence
   - Best use: stronger alternate for per-character feedback

4. `glass-interface-click.wav` — 199 ms
   - Source: Mixkit sound effect 2568, “Cool interface click tone”
   - Character: bright, synthetic, reflective
   - Best use: Space commit / word-to-tile placement

## Recommended pairing

- Letters: `laptop-key-press.wav`, played quietly with slight pitch variation.
- Space / committed word: `glass-interface-click.wav`, played once at a higher level.
- Enter / line lift: use a separate low, soft movement sound in a later pass.
