# disco-type-ux

An interactive 3D disco-ball typing prototype where words are printed onto
tile-owned facets as the sphere turns.

## Interaction modes

- **Mechanical** — click-clack feedback with immediate, tactile turns.
- **Flow** — forgiving continuous-typing music with smooth ball movement.

Space commits a word, Enter advances the writing line, and scrolling over the
ball rotates it horizontally.

## Run locally

Open `index.html` in a modern browser.

## Container

The included `Dockerfile` serves the prototype on port `8080`.
