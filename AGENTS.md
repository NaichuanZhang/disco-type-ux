# AGENTS.md

## Project rules

- Keep `index.html` as the dependency-free canonical entry and reference all assets with relative paths.
- Keep words owned by physical disco-ball facets. Do not introduce a separate text rail or sticker-like overlay.
- Preserve Space-to-commit, Enter-to-lift, automatic ring wrapping, wheel rotation over the ball, and typing-to-recenter behavior.
- Preserve both personalities: Mechanical uses immediate turns with click-clack samples; Flow uses forgiving cadence music and smooth retargeting.
- Keep reusable audio under `assets/sounds/`; avoid hotlinked media and do not commit local session metadata or design screenshots ignored by `.gitignore`.
- `Dockerfile` serves the site on port `8080`. Update the README production link whenever the deployed hostname changes.
